# Document Definition: SDV Simulator 구조 설계서

## Purpose

SDV(Software Defined Vehicle) 시뮬레이터 **sdv-simulator**의 현재 구조(architecture)를
설계서 형태로 정리한 문서. 단일 코어 엔진을 공유하는 v1(코어 라이브러리 + CLI)과
v2(웹 대시보드), 그리고 배포(deploy)까지 **전체 시스템의 구조**를 기술하고,
핵심 설계 영역(시뮬레이션 엔진, 통신 충실도, 앱 런타임, 리플레이)은 클래스/시퀀스
수준까지 상세히 설명한다.

## Audience

- **과제 평가자(교수/채점자)** — 코드를 직접 읽지 않아도 이 문서만으로 프로젝트의
  구조와 핵심 설계의 타당성을 파악할 수 있어야 한다.

## Scope

- 전체 시스템 구조: `sdv_sim` 코어(엔진·스키마·CLI), v2 대시보드(FastAPI 서버 + React 프런트엔드), 배포(deploy/)
- 계층 구조, 모듈 경계, 데이터 흐름, 주요 객체(클래스) 관계, 핵심 시퀀스(실행 경로·리플레이 경로)
- 핵심 설계 영역의 상세:
  - 시뮬레이션 엔진(이산 사건 엔진, 이벤트 큐, 결정성)
  - 통신 충실도 모델(CAN/Ethernet, 게이트웨이 라우팅)
  - 앱 런타임(주기 태스크 스케줄링, 컴포넌트 API)
  - 검증·자동화(assertion, 이벤트 로그, 종료 코드)
  - 대시보드 데이터 흐름·리플레이(세션, 시크 인덱싱)
  - 프런트엔드 구조(구조 뷰 렌더링, 파일 접근, i18n)
- 설계 근거: 핵심 ADR/ASR 인용 (전체 ADR 목록은 부록)
- 실행 예로 `samples/`를 한두 곳에서 언급
- 다이어그램: Mermaid (클래스 다이어그램, 시퀀스 다이어그램, 흐름도)

## Out of Scope

- 모든 클래스/함수의 구현 수준 상세 (핵심부만 상세)
- 개발 과정 기록: `prompts.md`, `TODO-v1.md`, `TODO-v2.md`
- 스펙 검증 산출물: `verification/`
- 실행 산출물: 루트의 `events.json`
- 차량 동역학·ADAS·OTA·v3 데스크톱 등 후속/미구현 기능 (방향성 언급만 허용)

## Validation Criteria

1. **구조 파악 가능**: 평가자가 코드를 읽지 않아도 전체 아키텍처(계층·모듈·데이터 흐름)를 이해할 수 있다.
2. **핵심 설계 설명력**: 시뮬레이션 엔진의 이벤트 루프·통신 충실도 모델·스케줄링, 대시보드 리플레이 등 핵심부가 다이어그램(클래스/시퀀스)과 함께 설명되어 있다.
3. **정합성**: 문서의 다이어그램·용어·구조가 실제 코드 및 spec/ADR과 일치한다.
4. **설계 근거**: 주요 구조 결정이 ADR/ASR과 연결되어 "왜 이렇게 설계했는지"를 보여준다.

## Constraints

- 분량 제한 없음 (목표: 본문 15~25페이지 상당, 평가자가 읽기 좋은 수준)
- 최종 형식: Markdown 파일 하나 (`report/` 내)
- 언어: 한국어 (식별자·용어는 코드/스펙의 원어 유지)
- 다이어그램: Mermaid 코드 블록 (외부 이미지 없음)
